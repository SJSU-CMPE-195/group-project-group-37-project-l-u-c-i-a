### Reconnect Roomba

Christian asked for a "hardware reset" button for when the Roomba dies. Until
now, after the Roomba was turned off and on, `roomba_bridge` had to be restarted
(Stop + Start mapping), which also threw away the map being built.

- `roomba_bridge` (`lucia_control`): new service `~/reconnect`
  (`/roomba_bridge/reconnect`, `std_srvs/Trigger`). It stops the wheels, reopens
  the serial port, wakes the Roomba (BRC pulse; only does something if the cable
  has that wire), sends Start (128) and Safe (131), and plays a short beep: since
  nothing comes back from the Roomba over serial, the beep is the confirmation.
  Takes about 5 s. Serial errors while driving (adapter unplugged) are now logged
  once instead of crashing the node; a failed reconnect leaves it running with
  the wheels stopped.
- `RoombaOI.beep()` (song opcodes 140/141, slot 3), ROS2 copy only, with a byte
  test; `lucia_control` has 22 tests.
- `web_ui`: `/api/roomba/reconnect` stops a running mission first (so it doesn't
  drive off the moment the Roomba wakes), calls the service and returns its
  answer. The page has a **Reconnect Roomba** button in the Mapping card.
- Checked here: the reconnect, error and shutdown paths with ROS and the Roomba
  faked out; the button against the stub (43/43 browser checks). Not yet tried
  on the robot.

### Horn and tunes

Christian asked for a horn on the page, with tunes (Persona, Pokémon). The
Roomba's speaker plays one note at a time; it stores 4 songs of 16 notes.

- `lucia_control`: `song.py` (pure) checks a tune and splits it into slots, with
  start times so each slot follows the last; `RoombaOI.define_song` /
  `play_song`; `roomba_bridge` topic `~/song` (JSON notes) loads all slots, plays
  the first and starts the rest on one-shot timers (driving isn't held up); a new
  tune cancels the old one's timers. 37 tests.
- `lucia_web`: `tunes.py` (pure): built-in tunes (Horn, Charge!, and La Cucaracha
  and Mass Destruction from last semester's `song.py`); a text format for notes;
  a MIDI file reader (tempo changes, running status, one part per track and
  channel, drums marked) and melody extraction (highest note when notes start
  together, rests for gaps, 1/64 s grid, long notes split, cut to 64, octave
  shift, start time, counts notes outside the Roomba's range); saved tunes in
  `~/maps/tunes.json`. 99 tests in `lucia_web`, including MIDI files built
  byte by byte.
- Page: Horn in the header and the H key (not while typing); a *Horn and tunes*
  card: pick a tune, Play on Roomba, Preview here (Web Audio square wave), edit
  the notes with live checking, Save / Delete, Import from a MIDI file.
- Not transcribed from memory: the Persona and Pokémon melodies would likely come
