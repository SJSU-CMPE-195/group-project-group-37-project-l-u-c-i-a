### Keyboard bug found and fixed
The page ignored keys whenever any `<input>` had focus. One click on the speed
slider or a checkbox, and WASD / arrows stopped driving (the arrows moved the
slider instead), and **Space / Esc STOP did nothing**. Capital letters didn't
work either. Now keys work everywhere except while typing in a text box; Esc
stops even then; Space stops instead of clicking a focused button; held keys
light up the pad.

- **`update.sh` and `docs/Updating the Repo on the Pi.md` removed:** it joined a
  `lucia` WiFi that doesn't exist, bypassed NetworkManager, and ran
  `git clean -fd`.
- **Container stop fixed** (not yet tried on the Pi): restarts showed
  "Restarting 30.2s". `ros2 run` was the container's main process, and the main
  process of a container ignores SIGTERM unless it handles it, so Docker waited
  the whole 30 s grace period and force-killed everything. `web_ui` never got
  to stop mapping, and a kill while driving could leave the Roomba going at its
  last speed. `compose.yml` now has `init: true` and execs `web_ui` directly,
  which handles SIGTERM (rclpy) and stops mapping, so `roomba_bridge` stops the
  wheels. Takes effect after `docker compose -f docker/compose.yml up -d`.
- Considered, not done: letting NetworkManager run the hotspot's address server
  (`ipv4.method shared`) instead of the separate dnsmasq. Left as an option in
  TODO.md.
