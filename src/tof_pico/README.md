# ToF Sensing with Pico 2:

### Pico Set-up
1. add submodule "git submodule update --init"
2. copy library from submodule to pico 2 (refer to README in vl53lcx directory)
3. copy and run scripts from this directory


The streaming firmware (ToF + IMU) and the PC heat map viewer are in `src/pico2/`.
